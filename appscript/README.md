# Google Apps Script Integration

This folder contains Google Apps Script code used to integrate Google Sheets with the Inventory Management System.

## Files Description

| File Name | Description |
| :--- | :--- |
| `google-apps-script.js` | Complete Google Apps Script Web App code to be pasted into the Google Sheet Apps Script editor for real-time synchronization. |

Refer to [DEPLOYMENT.md](../DEPLOYMENT.md) for step-by-step instructions on deploying the Web App.
