# Helper & Deployment Scripts

This folder contains utility scripts for database generation and edge function deployments.

## Files Description

| File Name | Description |
| :--- | :--- |
| `deploy-daily-history.ps1` | PowerShell deployment script to configure Supabase secrets and deploy `daily-inventory-history` edge function. |
| `generate_product_rate_sql.js` | Node.js script to generate SQL queries for updating product rates. |
| `generate_product_rate_sql.ps1` | PowerShell version of the product rate SQL generator script. |
